- 2026-11-12 (later): 0.8.0 - the PowerShell/P-Invoke dialog implementation (VSDlg C# source, Add-Type, per-instance DLL cache) is REPLACED by direct user32 calls through the koffi FFI (prebuilt, bundled in the extension; npm dep 3.3.7). Donald rejected the Add-Type approach: it made every user's machine compile the Win32 binding at runtime. UI Automation was evaluated first and rejected on live evidence (the modal dialog never appears in UIA's root walk under Electron; the Cancel button presents as ControlType.Pane with no InvokePattern). Verified live on a disposable instance: enumeration finds &Open/Cancel/&Help; rung 1 and rung 2 dismissals report dismissed:true. One real difference found in testing: PostMessage is queued, so dismiss_dialog waits 200 ms before its verification re-enumeration (the PowerShell spawn used to supply that delay for free). Calls are now synchronous and instant.
- 2026-11-12 (evening): 0.8.1 save_file path normalisation, 0.8.2 close_file/findTab path normalisation (both found by the extension audit rounds), and 0.8.3 the dispatchCommand guard: run_command and every generated command tool race their dispatch against a 12 s timer and answer `pending: true` WITH the live native dialog list instead of awaiting a command that opened a modal. Cause: the Configure Default Formatter dialog during the beautify audit round left Donald waiting minutes; the old code had no way to answer. Verified live by raising the same dialog deliberately: the call now returns in 12.4 s with hwnd+buttons, one dismiss_dialog cancels it, the command continues. Rule for agents: a pending:true response means a dialog is up - call list_dialogs/dismiss_dialog, never re-run blindly.
- 2026-11-12 (latest): 0.8.4 self_test (12 checks, ~3 s, 12/12 on VS Code 1.146.0) and the harness fact that goes with it: opencode caches a server's tool list, so after a reload that ADDS tools the new one still answers "Unknown tool" while the server serves it. Reconnect with `opencode api post '/api/experimental/mcp/vscode-mcp/connect?location%5Bdirectory%5D=<cwd>'` - no file edit, no harness restart. Same tools after a plain reload need nothing but the pid poll.
